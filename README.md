# 一源多创 · 多平台图文（yiyuan-duochuang）

一个 WorkBuddy 技能：把一份素材（卖点、硬信息、实拍原图）改写成**抖音图文、视频号图文、公众号、小红书、携程**五个平台各自适配的图文稿和配图，交付一个带一键复制按钮的"发布总览"网页，由人工逐个平台发布。

- **分平台差异化**：每个平台一套"必须 / 禁止"规则，依据各平台官方规则页面，并附合格与不合格示例。
- **文案去 AI 味**：内置 [Humanizer-zh](https://github.com/op7418/Humanizer-zh) 的改写规则，压缩成 10 条清单给模型逐条执行。
- **配图**：通过中转 API 调用 image2.6，以原图为参考按最高分辨率出图，自动导出各平台尺寸并加"AI 生成"标识。
- **仿对标图**：用户给对标图时，先看图拆解版式结构，再用开源字体后期叠字，只仿结构不仿内容。
- **数据中台与发布建议**：借助 [socai](https://github.com/socai-io/socai) 采集自家、竞品和同类作品数据，生成"内容数据中台"网页；每次出稿前按上一次的数据给出发布建议和拍摄清单（拍什么、怎么拍、用在哪、预期效果、依据）。
- **优秀案例检索**：随时可以让它去平台内和网上找同行业的优秀案例，拆出可借鉴的地方。
- **风格库**：上传喜欢的对标图和文案，以后按它调整，并区分各平台调性。
- **AI 出稿，人工发布**：技能不调用任何发布接口；生图前、交付前各有一次用户确认。

## 安装到 WorkBuddy

1. 下载技能包：直接下载仓库里的 [`release/yiyuan-duochuang.zip`](release/yiyuan-duochuang.zip)（打开后点 Download raw file）。改过技能文件后，在仓库根目录运行 `bash build.sh` 重新打包，它会先按 WorkBuddy 技能规范校验格式。
2. 在 WorkBuddy 左侧进入【技能】→【添加技能】，上传这个 ZIP。
3. 准备运行环境（在运行 WorkBuddy 的电脑上）：
   - Python 3.8 及以上，并安装 Pillow：`python3 -m pip install pillow`
   - socai（建议安装，用于数据工作台）：在 WorkBuddy 技能市场添加"多平台社媒调研-Socai"，或按 https://socai.io/docs/installation/ 安装，然后在 Chrome 里登录小红书和抖音
   - image2.6 中转 API：准备好接口地址、模型名和 API Key

### 设置 API Key

API Key 只放在环境变量 `IMAGE_API_KEY` 里，不要发在对话里，也不要写进任何文件。

macOS（zsh）：

```bash
echo 'export IMAGE_API_KEY="你的Key"' >> ~/.zshrc && source ~/.zshrc
```

Windows（PowerShell，设置后重新打开 WorkBuddy）：

```powershell
setx IMAGE_API_KEY "你的Key"
```

## 第一次使用

在 WorkBuddy 里对它说"用一源多创做初始化"，然后把公司简介发给它（文字、PDF 或网页链接都可以）。它会按顺序做 7 件事：

1. 建数据目录、检查 Python、Pillow、socai
2. 接入 image2.6（填接口地址和模型名，测一次）
3. 从公司简介整理品牌信息和公司资料，只问简介里没写到的
4. 用 socai 拉取自家账号的历史作品，生成账号调性档案和第一版内容数据中台
5. 搜索五个平台的最新官方规则，补充到技能里
6. 下载 8 款开源免费商用字体
7. 汇总初始化结果，请你确认

之后你可以随时把喜欢的对标图片或文案发给它，说明用在哪个平台，它会存进风格库，以后照着调整。

## 再次使用：先复盘，再出稿

第二次及以后来用时，它会先做"第 0 步"：问你要不要更新数据，用 socai 采集自家账号最新数据，和上一次对比，写出诊断结论和本次发布建议（含给摄影师的拍摄清单），生成 `workbench/内容数据中台.html`。你可以按建议出稿，也可以用自己的素材出稿。

## 日常出稿

把素材包（文字资料和实拍原图，可以附上对标图）交给它，说"一源多创出稿"。流程是 9 步加 2 个交互点：

1. 素材拆解 → 内容卡
2. 拆解对标图（有对标图才做）
3. 对齐选题，检索优秀案例
4. 逐平台写文案并去 AI 味
5. 写出图指令
6. 脚本检查文案（字数、禁用词、硬信息、平台间重复、照抄）
7. **交互点 A**：你选标题、改文案、勾选要出的图
8. 调 image2.6 生成图片
9. 看图自查（错字、凭空多出的设施、版式）
10. 打包交付
11. **交互点 B**：你逐张确认图片和发布声明

主交付物是 `输出/<日期>_<主题>/发布总览.html`：每个平台一张卡片，有标题、正文、话题、配图和"复制全文 / 只复制标题 / 只复制正文"按钮，以及发布时要勾选的声明。同一文件夹里还有各平台的图片、纯文本文案和 `07_交付清单.md`。

## 目录结构

```text
yiyuan-duochuang/            技能目录（上传 WorkBuddy 的就是它）
├── SKILL.md                 主流程
├── references/              各平台规则、合规、去 AI 味、图片、对标、字体、socai 工作台、发布建议、优秀案例、风格库、规则刷新
├── templates/               内容卡、各平台输出字段、出图指令、对标拆解、品牌问卷、公司资料、发布建议、诊断结论、风格样本、案例记录、交互点、自查清单
└── scripts/                 setup_check / fetch_fonts / collect_data / dashboard / gen_image / overlay_text / lint / pack / render_publish
tools/validate_skill.py      WorkBuddy 技能格式校验与打包
build.sh                     一键校验并打包
release/yiyuan-duochuang.zip 打包好的技能，直接上传 WorkBuddy
```

使用时会在你的工作目录里生成三个文件夹，技能更新时不会被覆盖：

- `yiyuan-data/`：品牌信息、公司资料、接口配置（不含 Key）、字体、最新规则补充
- `workbench/`：socai 采集的数据、内容数据中台、优秀案例、风格库、账号调性档案
- `输出/`：每次出稿的结果

## 规则来源

各平台规则依据官方页面（小红书社区公约 2.0 与蒲公英内容审核规范、抖音生活服务素材发布要求、微信视频号与公众平台运营规范、携程内容中心与商家规则）和《广告法》《互联网广告管理办法》《人工智能生成合成内容标识办法》。规则会变，技能首次运行和之后每 30 天会提醒你重新检索；新规则写进 `yiyuan-data/rules-latest/`，与原规则冲突时由你决定。
