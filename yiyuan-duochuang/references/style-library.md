# 风格库：用户喜欢的对标图和文案

用户可以随时上传喜欢的对标图片或文案，让以后的出稿照着调整。风格库存在 `workbench/风格库/`，长期有效，不只用于当次。

```text
workbench/风格库/
├── 图片/<平台代号或"通用">/   对标图原图 + 同名的对标拆解 JSON
└── 文案/<平台代号或"通用">/   每篇一个 .md（格式见 templates/style_sample.md）
```

## 用户上传时怎么做

1. **先问用在哪个平台**（多选）：抖音图文 / 视频号图文 / 公众号 / 小红书 / 携程 / 所有平台。用户已经说了就不再问。
2. **对标图**：按 benchmark.md 拆解，图片和拆解 JSON 一起存进对应平台的文件夹。选了"所有平台"就存进"通用"。
3. **文案**：按 `templates/style_sample.md` 存原文并拆写法，存进对应平台的文件夹；选了"所有平台"就存进"通用"。
4. **回复用户**：用一两句话说你从中学到了什么，以及会用在哪些平台。

## 出稿时怎么用

**写文案（第 ④ 步）**，按下面的优先级借鉴，排在前面的说了算：

1. 平台规则（platform-<平台>.md）：永远优先，风格不能违反规则。
2. 风格库里本平台的文案样本（`风格库/文案/<平台代号>/`）。
3. 账号调性档案（`workbench/账号调性/<平台代号>.md`）。
4. 品牌信息里的语气。

**做配图（第 ⑤ 步）**：

1. 本次用户新给的对标图。
2. 风格库里本平台的对标图：没有新对标图时，默认用它，`text_mode` 填"底图叠字"，按它的拆解填 `text_layers`。
3. 品牌信息里的视觉风格。

## 区分各平台调性

- 某个平台的样本只用在这个平台。小红书的样本不能拿来写公众号。
- "通用"样本只借叙述手法，例如"用一个人物带出酒店""第一句先给结论"。字数、分段、emoji、标题句式这类格式，各平台仍按自己的规则写。
- 同一个样本用到多个平台时，各平台的稿子仍要分别从内容卡重写，不能互相改写；lint.py 的平台间重复检查照样生效。
- 只学写法，不搬内容：样本里的事实、数字、人物、原句都不能进新稿。lint.py 会检查，与样本原文连续 12 个字相同就提示。

## 什么时候提醒用户

在这三个时候提醒一次（原话见 brand_onboarding.md 第四步、interaction_b.md 的结束语）：

- 首次运行结束时；
- 每次交付结束时；
- 用户对某张图或某篇文案说"不喜欢"的时候，顺便问一句有没有喜欢的样子可以发来参考。
