# 规则刷新

首次运行必做，之后每 30 天提醒用户一次。目的：把各平台最新的官方规则和方法论补充到技能里。

每个平台再加一个方法论检索词，例如"小红书 种草方法论 最新"，这一项可以采用第三方文章。

## 写入位置和格式

写进 `yiyuan-data/rules-latest/<平台代号>.md`，每条一段：

```markdown
### <一句话规则>
- 类型：必须 / 禁止 / 方法论参考
- 级别：【官方】或【经验】
- 来源：<链接>
- 检索日期：YYYY-MM-DD
- 与现有规则的关系：新增 / 与 platform-<平台>.md 第 N 条冲突 / 重复（重复的不写）
```

## 必须遵守

1. 只有官方域名上的内容能写成"必须"或"禁止"；第三方文章只能写成"方法论参考"，并标【经验】。
2. 每条都写来源链接和检索日期。
3. 与现有规则冲突的条目，列出来让用户选："采用新规则 / 保留原规则 / 稍后处理"。用户的选择写进该条的"与现有规则的关系"。
4. 红线只加不删。要删除或放宽任何"禁止"，必须用户明确同意。
5. 搜不到、或者搜到的内容模糊时，保留现有规则，不猜。
6. 写完运行 `python3 <技能目录>/scripts/setup_check.py --mark rules_refreshed`，记下刷新日期。
