# socai 数据工作台

socai 装在使用者自己的电脑上，复用已登录的 Chrome 读取平台公开内容。它是本技能的数据工作台：采集自家、竞品和搜索样本的数据，整理成表，生成"内容数据中台"网页，给第 0 步复盘、选题、对标和学习账号调性用。socai 只读，禁止用它发帖、评论、点赞、关注、私信。

| 平台 | socai 是否支持 | 能拿到的数据 |
| --- | --- | --- |
| 小红书 | 支持 | 搜索结果、博主主页、笔记正文、点赞收藏评论、评论内容、图中文字（OCR）、原图下载 |
| 抖音 | 支持 | 搜索结果、作者主页、作品描述、点赞评论分享、热门评论 |
| 公众号 | 支持 | 按关键词搜文章、读全文 |
| 视频号 | 不支持 | 视频号助手导出后放进 `workbench/手动导入/` |
| 携程 | 不支持 | 携程内容中心数据看板导出后放进 `workbench/手动导入/` |

## 工作台文件夹（在用户工作目录里）

```text
workbench/
├── raw/                 socai 原始结果，按下面的规则命名
├── 手动导入/            视频号、携程等导出的 CSV
├── 数据/                collect_data.py 整理出的表，和模型写的三个 JSON
│   ├── 作品明细.csv  账号.csv  选题样本.csv  meta.json
│   ├── 诊断结论.json  发布建议.json  经营基本面.json
│   └── 历史/<日期>/     每次采集的快照，用来和前一天对比
├── 内容数据中台.html     dashboard.py 生成的数据中台网页
├── 优秀案例.md           案例检索记录（case-research.md）
├── 风格库/               用户喜欢的对标图和文案（style-library.md）
├── 账号调性/             各平台的账号调性档案
└── 对标库/               对标笔记的原图和拆解
```

## 开始前

1. `socai version --no-check --json` 确认已安装；`socai status --json` 确认浏览器就绪。
2. 每个新任务先登记一次：把用户原话写进一个临时 JSON 文件 `{"user_prompt":"用户原话","agent_host":"workbuddy"}`，运行 `socai task begin --context-file <文件>`，然后删掉这个临时文件。禁止把用户原话直接拼进命令行。
3. 命令参数以本机 `socai <平台> --help` 为准。

## 结果怎么存

每条 socai 命令的输出都重定向成一个文件，存进 `workbench/raw/`，文件名必须是：

```text
<YYYY-MM-DD>_<xhs|dy|weixin>_<自家|竞品|搜索>_<说明>.json
```

例如：

```bash
socai xhs author <自家ID> --num-notes 30 > "workbench/raw/2026-11-23_xhs_自家_主号.json"
socai dy author <竞品ID> --num 30 > "workbench/raw/2026-11-23_dy_竞品_同城某酒店.json"
socai xhs search "亲子酒店" --num-notes 20 --num-comments 8 > "workbench/raw/2026-11-23_xhs_搜索_亲子酒店.json"
```

视频号、携程导出的数据另存为 CSV 放进 `workbench/手动导入/`，表头：`平台,账号,标题,点赞,收藏,评论,分享,发布日期,链接`。

存完后运行整理脚本，它负责数字换算（"1.2万"等）、去重和保存快照：

```bash
python3 <技能目录>/scripts/collect_data.py
```

## 任务

| 任务 | 什么时候 | socai 命令（示例） | 用在哪 |
| --- | --- | --- | --- |
| 每日复盘采集 | 每次再次使用时（第 0 步），数据不是今天的就先问用户 | `socai xhs author <自家ID> --num-notes 30`；`socai dy author <自家ID> --num 30` | 内容数据中台、发布建议 |
| 选题扫描 | 每两周，或新选题时 | `socai xhs search "<词>" --num-notes 20 --num-comments 8`；`socai dy search "<词>" --num 20`；`socai weixin search "<词>" --num 10` | 选题样本、优秀案例 |
| 对标收集 | 用户给链接时 | `socai xhs get-notes --note '<id>=<token>' --ocr --download-media` | 对标库、风格库 |
| 账号调性采集 | 首次运行，之后每月 | 见下方"账号调性档案" | 账号调性 |
| 竞品监测 | 每月 | `socai xhs author <竞品ID>`；`socai dy author <竞品ID>` | 内容数据中台 |

关键词池由目的地词 × 品类词 × 人群词组成，首次运行时按品牌信息和公司资料生成初稿，用户可以增删，存进 `workbench/关键词池.txt`。

## 生成内容数据中台

模型写好 `诊断结论.json` 和 `发布建议.json`（规则见 publish-advice.md）后运行：

```bash
python3 <技能目录>/scripts/dashboard.py
```

页面上的数字全部由脚本从数据表计算，模型不手写数字。页面包含：总览、账号矩阵、平台表现、作品明细（可搜索、筛选、排序）、经营基本面（有 `经营基本面.json` 才显示）、诊断结论、本次发布建议和拍摄清单。

## 账号调性档案

socai 能拉到自家账号主页上公开的作品：小红书最完整，抖音要分两步拉，公众号只能搜到多少读多少。仅自己可见和已删除的作品拉不到。

| 平台 | 怎么拉 | 能拿到 |
| --- | --- | --- |
| 小红书 | `socai xhs author <自家ID> --num-notes 30 --ocr --download-media` | 主页资料，以及每篇笔记的标题、正文、图片、图中文字、互动数、评论 |
| 抖音 | 先 `socai dy author <自家ID> --num 30` 拿作品列表，再对每条用 `socai dy get-videos --video <链接>` 读详情 | 标题、描述、话题、发布时间、互动数、封面、热门评论 |
| 公众号 | 用 `socai weixin search "<公众号名>" --read` 搜到多少读多少，或由用户给文章链接后用 `socai weixin read '<链接>'` | 标题、全文、图文顺序、发布时间 |
| 视频号、携程 | 不支持 | 用户上传截图或后台导出 |

拉到的作品按 `templates/voice_profile.md` 填成 `workbench/账号调性/<平台代号>.md`。使用规则：

1. 第 ④ 步写文案时，先读本平台的调性档案，再按平台规则写；风格库里有本平台的文案样本时，样本优先（见 style-library.md）。
2. 只学说话方式（句长、用词、标点、叙述习惯），不把样本里的经历、数字、价格搬进新稿。
3. 调性和平台规则冲突时，平台规则优先；样本里用过的绝对化用语，新稿也不能用。
4. 某平台样本少于 5 篇时不生成档案，按品牌信息里的语气写，并在交付清单里提示。
5. 每月更新一次。

## 同一选题的平台分工

| 平台 | 在同一选题里的角色 | 看哪些数 |
| --- | --- | --- |
| 抖音 | 引爆曝光，让没想过的人想去 | 图文浏览量、互动率 |
| 视频号 | 熟人信任，导入私域和直播 | 转发数、加企微数、直播预约数 |
| 公众号 | 深度攻略，沉淀品牌资产 | 阅读数、分享数、收藏数 |
| 小红书 | 搜索种草，占住攻略关键词 | 收藏数、搜索排名、评论咨询数 |
| 携程 | 决策转化，把想去变成下单 | 曝光、订单转化（内容中心看板） |

## 采集红线

- 只读：不发帖、不评论、不点赞、不关注、不私信。
- 引用样本必须带链接和发布日期；小红书搜索按相关性排序，逐条核对日期。
- 遇到登录、验证码、限流立即停止，如实告诉用户，不重复硬试。
- 采集来的内容只学结构和选题，不照搬他人文案和图片。
- 互动数由 collect_data.py 换算；页面隐藏的数（例如只显示"收藏"二字）记为空，不当成 0。
