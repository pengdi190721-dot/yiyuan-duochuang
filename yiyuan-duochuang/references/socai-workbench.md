# socai 数据工作台

socai 装在使用者自己的电脑上，复用已登录的 Chrome 读取平台公开内容。它是本技能的数据工作台：定期采集小红书、抖音、公众号的公开内容，存进 `workbench/`，供选题、对标、学习账号调性和排期使用。socai 只读，禁止用它发帖、评论、点赞、关注、私信。

| 平台 | socai 是否支持 | 能拿到的数据 |
| --- | --- | --- |
| 小红书 | 支持 | 搜索结果、博主主页、笔记正文、评论、图中文字（OCR）、原图下载 |
| 抖音 | 支持 | 搜索结果、作者主页、作品描述、评论 |
| 公众号 | 支持 | 按关键词搜文章、读全文 |
| 视频号 | 不支持 | 视频号助手导出后放进 `workbench/手动导入/` |
| 携程 | 不支持 | 携程内容中心数据看板导出后放进 `workbench/手动导入/` |

## 工作台文件夹（在用户工作目录里）

```text
workbench/
├── 选题机会表.csv    话题、平台、样本链接、发布日期、互动数、评论高频问题、建议主打平台
├── 账号调性/         各平台的调性档案和样本作品
├── 对标库/           爆款笔记的链接、原图、OCR 文字、对标拆解 JSON
├── 自家复盘.csv      自家账号公开作品的互动数
├── 竞品监测.csv      竞品账号最近的作品和互动数
├── 手动导入/         视频号助手、携程内容中心导出的数据
└── 排期表.csv        下两周每个选题 × 平台 × 发布日期
```

## 开始前

1. `socai version --no-check --json` 确认已安装；`socai status --json` 确认浏览器就绪。
2. 每个新任务先登记一次：把用户原话写进一个临时 JSON 文件 `{"user_prompt":"用户原话","agent_host":"workbuddy"}`，运行 `socai task begin --context-file <文件>`，然后删掉这个临时文件。禁止把用户原话直接拼进命令行。
3. 命令参数以本机 `socai <平台> --help` 为准。

## 五类任务

| 任务 | 频率 | socai 命令（示例） | 写入 |
| --- | --- | --- | --- |
| 选题扫描 | 每两周 | `socai xhs search "<词>" --num-notes 20 --num-comments 8`；`socai dy search "<词>" --num 20`；`socai weixin search "<词>" --num 10` | 选题机会表.csv |
| 对标收集 | 用户给链接时，或每月 | `socai xhs get-notes --note '<id>=<token>' --ocr --download-media` | 对标库/ |
| 账号调性采集 | 首次运行，之后每月 | 见下方"账号调性档案" | 账号调性/ |
| 自家复盘 | 发布后第 7 天 | `socai xhs author <自家ID> --num-notes 20`；`socai dy author <自家ID> --num 20` | 自家复盘.csv |
| 竞品监测 | 每月 | `socai xhs author <竞品ID>`；`socai dy author <竞品ID>` | 竞品监测.csv |

关键词池由目的地词 × 品类词 × 人群词组成，首次运行时按品牌信息生成初稿，用户可以增删，存进 `workbench/关键词池.txt`。

## 账号调性档案

socai 能拉到自家账号主页上公开的作品：小红书最完整，抖音要分两步拉，公众号只能搜到多少读多少。仅自己可见和已删除的作品拉不到。

| 平台 | 怎么拉 | 能拿到 |
| --- | --- | --- |
| 小红书 | `socai xhs author <自家ID> --num-notes 30 --ocr --download-media` | 主页资料，以及每篇笔记的标题、正文、图片、图中文字、互动数、评论 |
| 抖音 | 先 `socai dy author <自家ID> --num 30` 拿作品列表，再对每条用 `socai dy get-videos --video <链接>` 读详情 | 标题、描述、话题、发布时间、互动数、封面、热门评论 |
| 公众号 | 用 `socai weixin search "<公众号名>" --read` 搜到多少读多少，或由用户给文章链接后用 `socai weixin read '<链接>'` | 标题、全文、图文顺序、发布时间 |
| 视频号、携程 | 不支持 | 用户上传截图或后台导出 |

拉到的作品按 `templates/voice_profile.md` 填成 `workbench/账号调性/<平台代号>.md`。使用规则：

1. 第 ④ 步写文案时，先读本平台的调性档案，再按平台规则写。
2. 只学说话方式（句长、用词、标点、叙述习惯），不把样本里的经历、数字、价格搬进新稿。
3. 调性和平台规则冲突时，平台规则优先；样本里用过的绝对化用语，新稿也不能用。
4. 某平台样本少于 5 篇时不生成档案，按品牌信息里的语气写，并在交付清单里提示。
5. 每月随自家复盘更新一次。

## 总体规划（每两周）

1. 汇总选题机会表、自家复盘、竞品监测和手动导入的数据。
2. 给出下两周排期草案：每个选题主打哪个平台，其余平台按下表分工配合。
3. 让用户勾选要做的选题（多选），可以改日期（填写），确认后写进排期表.csv。

| 平台 | 在同一选题里的角色 | 看哪些数 |
| --- | --- | --- |
| 抖音 | 引爆曝光，让没想过的人想去 | 图文浏览量、互动率 |
| 视频号 | 熟人信任，导入私域和直播 | 转发数、加企微数、直播预约数 |
| 公众号 | 深度攻略，沉淀品牌资产 | 阅读数、分享数、收藏数 |
| 小红书 | 搜索种草，占住攻略关键词 | 收藏数、搜索排名、评论咨询数 |
| 携程 | 决策转化，把想去变成下单 | 曝光、订单转化（内容中心看板） |

## 采集红线

- 只读：不发帖、不评论、不点赞、不关注、不私信。
- 引用样本必须带链接和发布日期；小红书搜索按相关性排序，逐条核对日期。
- 遇到登录、验证码、限流立即停止，如实告诉用户，不重复硬试。
- 采集来的内容只学结构和选题，不照搬他人文案和图片。
- 数量和字符串不要混用：`999+`、"1.2万"这类互动数先换算再比较。
