# 交互点 B：确认成品（在交付之前）

目的：用户逐张确认图片，处理审核报告里的遗留问题，确认发布声明。

## 做法

1. 逐个平台展示：每张导出图（文件路径）、文案终稿、`06_审核报告.md` 里该平台的 FAIL / WARN 摘要、`needs_human` 列表。
2. 按下表提问。能用选项卡片就用卡片，不能就让用户回复编号。
3. 用户选"重新生成"或"改为叠字"的图，按选择重做（`gen_image.py --slot`），再回到这一张重新问。
4. 用户的回答原样追加到 `交互记录.md`。全部处理完后跑第 ⑨ 步，然后按下面的"结束语"收尾。

## 结束语（原样使用，替换尖括号里的内容）

> 这次的稿子都在 <输出目录>/发布总览.html，用浏览器打开，每个平台点「复制全文」粘贴发布，配图按页面上的顺序上传。发布时记得勾选页面红框里提醒的声明。
>
> 两个小提醒：
> 1. 你可以随时把喜欢的对标图片或文案发给我，说明用在哪个平台。以后出图、写文案会照它调整，但各平台仍保留自己的调性。
> 2. 发布后明天再来找我，我会先更新数据中台，按这次的数据给你下一次的发布建议和拍摄建议。

## 问题

| 问题 | 方式 | 选项 |
| --- | --- | --- |
| 第 N 张图怎么处理？ | 单选（每张图问一次） | 通过 / 重新生成（填原因）/ 改为叠字 / 删掉 |
| 审核报告里的"需人工"项怎么处理？ | 单选（每项问一次） | 已处理 / 带着问题交付 / 退回重写 |
| 体验分享类稿件含价格和预订方式，要标"广告"吗？（lint.py 有这条 WARN 时才问） | 单选 | 标"广告" / 勾选平台的营销推广声明 / 两个都做 |
| 发布声明 | 确认 | 我知道发布时要勾选 AI 生成和营销推广声明 |
| 发布人和计划日期 | 填写 | 可跳过 |

## 交互记录格式

```markdown
## 交互点 B · <平台名> · <时间>
- 图片：<slot>：<用户选择>（每张一行）
- 需人工项：<处理方式>
- 广告标识：<用户选择>
- 发布声明：已确认
- 发布人 / 日期：<填写内容>
```
