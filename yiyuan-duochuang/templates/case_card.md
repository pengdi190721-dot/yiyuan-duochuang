# 优秀案例记录格式

每条案例按下面的格式追加到 `workbench/优秀案例.md` 末尾（以"### "开头，setup_check.py 按它计数）。只记录真实能打开的链接，数据注明来源，看不到的写"未公开"。

```markdown
### <案例名称或标题>
- 平台：小红书 / 抖音 / 视频号 / 公众号 / 携程 / 其他
- 链接：<能打开的链接>
- 发布方：<账号名或品牌>　发布日期：YYYY-MM-DD（超过 12 个月的标注"可能过时"）
- 检索方式：socai 平台内搜索 / 联网搜索（检索词：<原词>）
- 数据：<点赞、收藏、评论，或文章里写的效果；注明来源；没有就写"未公开">
- 为什么好：<标题 / 开头 / 结构 / 画面 / 互动设计，最多 3 条，每条一句>
- 可以借鉴：<落到本次哪个平台的哪一步，例如"小红书封面：人物抓拍 + 上方留白放标题">
- 不能照搬：<原文、照片、Logo、人物，以及只适用于对方的条件>
- 检索日期：YYYY-MM-DD
```
